# SurgiPrep 7.23.2 Beta — Mostrar la explicación al responder

Basada en 7.23.1. Al elegir una respuesta en Estudio, correcta o incorrecta, la pantalla se desplaza suavemente hasta el resultado y la explicación principal. También se aplica a una respuesta por voz que utilice el controlador habitual.

El análisis de alternativas permanece plegado. El desplazamiento deja espacio para la zona segura superior y respeta reducción de movimiento (desplazamiento inmediato). No se aplica al responder durante un Examen, cuya corrección permanece oculta hasta finalizar. No se ejecuta un desplazamiento pendiente si se ha cambiado de pregunta, sesión, modalidad o panel, o si la página se ha ocultado.

Banco de 2.000 preguntas y recursos idénticos a 7.23.1. Misma persistencia, audio y ajustes. Versión, tutorial y caché actualizados. Paquete completo para GitHub Pages, sin desplegar.

Comprobaciones de estado con DOM simulado; sin navegador ejecutable ni prueba visual/física en iPhone/iPad. Ver auditoria/PRUEBAS_V7_23_2.json. Validación clínica independiente pendiente.
