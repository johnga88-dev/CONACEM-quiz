CONACEM Quiz 1000
=================
- 500 preguntas Base originales
- 500 preguntas Especialista tipo examen/caso
- Filtro Base / Especialista / Todas
- Rendimiento persistente por pregunta y por tema
- Dominado >=85% con al menos 10 respuestas
- En progreso 70–84%
- Débil <70%
- Modo Temas débiles
- Modo Solo falladas
- Botón Reportar pregunta en cada ítem
- Motivo + nota libre
- Reportes guardados localmente
- Exportación de reportes en JSON

ACTUALIZAR GITHUB PAGES
1. Descomprime el ZIP.
2. Reemplaza todos los archivos en la raíz de tu repositorio.
3. Commit changes.
4. Si la PWA conserva caché antigua, elimina el icono de pantalla de inicio y vuelve a añadirla desde Safari.
