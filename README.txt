CONACEM CIRUGÍA V3 — REHECHA
============================

BANCO
- 2.000 preguntas.
- 20 módulos, 100 preguntas por módulo.
- 500 objetivos clínicos distintos.
- 500 preguntas de objetivo único.
- 1.500 preguntas integrativas de dos objetivos, diseñadas para que varias combinaciones sean parcialmente plausibles.
- 179 ítems incluyen esquemas visuales/anatómicos.
- 5 alternativas por pregunta.
- Cada pregunta tiene subtema, dificultad, explicación ampliada, análisis de alternativas y enlace directo a fuente.

ANTI-REPETICIÓN
- Modo “Variedad máxima”: no repite un mismo objetivo clínico dentro de la sesión.
- Modo Examen: no permite que dos preguntas compartan objetivo clínico en el mismo simulacro.
- Así se evita acertar por memoria de formulación aunque existan diferentes formas de evaluar el mismo conocimiento.

MODO ESTUDIO
- Feedback inmediato.
- Explicación desarrollada.
- “Por qué sí / por qué no” para alternativas.
- Fuente clicable.
- Casos con laboratorios.
- Preguntas con esquemas.
- Temas débiles, falladas y repetición espaciada.
- Favoritos y reportes.

MODO EXAMEN
- 20 / 50 / 100 / 150 preguntas.
- Temporizador opcional.
- Sin feedback hasta finalizar.
- Marcar para revisar.
- Resultado global y por tema.
- Revisión posterior con explicación y fuentes.
- Referencia configurable en código actualmente mostrada en 65%.

INSTALACIÓN
1. Descomprime este ZIP.
2. Reemplaza en la raíz de tu repositorio GitHub Pages TODOS los archivos de la versión anterior.
3. Sube también la carpeta assets completa.
4. Commit changes.
5. Abre la URL de GitHub Pages en Safari.
6. Si ves la versión anterior por caché, elimina el icono de pantalla de inicio y vuelve a añadirla desde Safari.
