SurgiPrep V6.0 Editorial

Esta versión contiene 80 preguntas del primer lote editorial revisado.
Meta del proyecto: 3000 preguntas validadas.

REGLAS V6
- Cada pregunta es autónoma y explícita.
- No se copian frases de manuales como enunciados.
- Cinco alternativas responden a la misma variable clínica/técnica.
- Explicación y análisis específico de cada alternativa.
- Fuentes actuales internacionales cuando corresponda.
- Los manuales del usuario se usan como guía temática, no como verdad absoluta.
- Contenido desactualizado se corrige o se excluye.
- Siglas desarrolladas junto a su significado.
- Laboratorios con rango normal de referencia junto al resultado.

Este lote es deliberadamente menor que 3000: no se añadieron preguntas no revisadas solo para alcanzar una cifra.
