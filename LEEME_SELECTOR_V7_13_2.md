# SurgiPrep 7.13.2 Beta

El selector Estudio / Examen ocupa ahora toda la fila del área de práctica. Cada botón utiliza la mitad del espacio disponible, tanto en teléfono como en tableta y escritorio. Se elimina el límite anterior de 420 píxeles.

Conserva la corrección de letras duplicadas, las sesiones y la práctica por voz. Las 1.419 preguntas y sus marcas no cambian.

Exporta un respaldo y sustituye los archivos de GitHub Pages por el contenido descomprimido, manteniendo el repositorio y la ruta. Abre la aplicación con conexión y vuelve a abrirla tras actualizar. No borres los datos del sitio.

Verificación: regla de ancho completo y reparto igual de botones comprobados en el código; banco y avisos idénticos a la versión anterior. Sin nueva comprobación visual en dispositivos físicos. Para las instrucciones generales, consulta los documentos de las versiones anteriores incluidos.
